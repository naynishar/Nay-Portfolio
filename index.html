MSc Research

AI-Assisted Project Planning

Design and Evaluation of an AI-Assisted Project Planning Tool for Improving Work Breakdown Structure and Scheduling Accuracy

This capstone research investigates whether generative AI can meaningfully improve project planning quality — specifically in Work Breakdown Structure completeness, logical sequencing, and schedule accuracy — compared to traditionally developed plans.

The study builds and evaluates a live prototype tool (Streamlit + GPT-4o API) across three real project scenarios: website development, event management, and mobile app planning. Each AI-generated plan is assessed against four quality criteria drawn from PMBOK and Kerzner (2022).

PMBOK Framework Generative AI GPT-4o Agile / Scrum WBS Analysis Prompt Engineering

Companion book in progress: "The AI-Powered Project Manager: A Practical Toolkit for Smarter Planning" — translating the empirical findings into accessible guidance for PMs, startup founders, and team leads. Expected Late 2026.
